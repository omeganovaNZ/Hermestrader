# 10-Stock Forward Test — 2026-10-26

A forward test of the system's stock selection, using **only information available up to
2026-10-26**. Review date: **2027-04-26** (6 months).

## Method

1. **Universe** — names with a verified fundamentals record in `src/fundamentals.py`
   (the registry built from company IR / SEC filings).
2. **Gate** — must pass `fundamental_check`: revenue growth ≥ 3%, EPS growth ≥ 0, margins
   not contracting, guidance not cut. 19 of 27 registry names pass.
3. **Momentum** — 6-month relative strength, capped at +60% so the most extended names
   can't dominate.
4. **Fundamentals** — `fundamental_score`, capped at 200.
5. **Score** — z-score of capped fundamentals + z-score of capped momentum.
6. **Diversification** — max 2 names per theme (the portfolio's own 40% theme cap in spirit).

## Test parameters

- **Review date:** 2027-04-26.
- **Measure:** price change of each pick from 2026-10-26 to 2027-04-26; equal-weight
  portfolio return; median and mean.
- **Benchmark:** equal-weight return of the full screener universe over the same window.
- **Success:** portfolio return > benchmark.

## Caveats (stated plainly)

- The selection framework has **no proven forward edge** — the fair test showed the
  screener picks underperform the universe, and the fundamentals gate *reduced* forward
  return on the last 3-year window.
- The picks are **momentum-tilted** (DDOG +103%, CRWD +127% over 6 months). The backtest
  showed momentum is *anti-predictive* on this data — extended names can mean-revert.
- Fundamentals are the **2026-curated registry**, not point-in-time 2026-10-26 filings for
  every name.
- One 6-month window proves nothing. This is a record of a hypothesis, not a prediction.
